# 端侧界面结构参考

复刻的参考对象是「滴答清单 / TickTick」Android v8.1.2 的**功能与信息架构**（布局、交互模式、模块划分），不使用其品牌资产（名称、图标、配色素材均为自绘/自定）。两端共用一套后端与数据模型，但**各自采用符合平台的界面范式**。

## 模块与开关

四个功能模块（专注/习惯/四象限/日历）均可通过设置关闭：关闭后入口隐藏、直接访问路由自动回到「今天」。两端读取同一份 `user_settings`。

## Web（桌面端，Next.js）

- **三栏布局**：左栏 260px（用户区/搜索/智能清单含计数/文件夹清单树/标签）× 中栏任务列表 × 右栏详情面板（≥1024px 常驻；窄屏为右侧滑出抽屉 + 遮罩 + ESC 关闭）
- 任务行：圆形勾选、标题、优先级色旗、截止时间 chip（过期红/今天橙/其他灰）、标签 chip、子任务与检查项计数；悬停显示操作
- 列表头：分组切换（清单/日期/优先级/四象限）、标签筛选、内联快速添加
- 视图：日历（月网格 + 议程）、专注（圆环计时 + 配置面板 + 今日/近 7 天统计）、习惯（卡片 + 12 周热力图）、四象限（2×2 拖拽改优先级）
- 主题：浅色/深色/跟随系统（class 策略），无刷新白闪

## Android（移动端，Compose）

- **底部导航**：任务 / 日历 / 专注 / 习惯 / 更多（模块开关动态显隐）；四象限入口在任务页顶栏
- 任务页：智能清单 chips（收件箱/今天/未来 7 天/所有）、任务列表（重复图标/子任务计数/优先级旗）、FAB 快速添加（底部弹层）、详情页编辑
- 抽屉：全部清单/文件夹/标签，可新建清单
- 专注：全屏圆环计时 + 前台服务常驻通知（暂停/放弃 action）
- 习惯：卡片打卡（计数型点按累加）、热力图；四象限：长按拖拽
- 提醒：精确闹钟（锁屏通知、点击直达任务、开机重建）；深色模式跟随系统

## 与后端的约定

- 客户端显示用「有效到期」= `COALESCE(next_due_date, due_date)`（重复任务滚动后以新日期参与"今天/未来 7 天"）
- BigInt（seq/sortOrder）在 JSON 中统一为字符串
- 智能清单谓词与四象限规则的常量集中在 `packages/contracts/src/{smartLists,priority}.ts`，两端保持同一语义
